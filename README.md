# Vikrant Iron / Vikrant Group Website

Responsive multi-page corporate website built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Group introduction, company ecosystem, portfolio and enquiry CTA
- `about.html` — Company profile and journey
- `products.html` — Product portfolio
- `solutions.html` — Industries and applications
- `contact.html` — Contact and enquiry form

## Run
Open `index.html` in a modern browser. No build step or package installation is required.

## Brand assets
The approved user-provided logos are stored in `assets/`:
- `vikrant-group-logo.jpg` — primary group logo
- `vikrant-iron-logo.png`

- `neelkanth-logo.png`

## Before public launch
1. Verify company descriptions, dates, product claims and brand relationships.
2. Confirm public phone, email and office address.
3. Replace sample stock photography with approved plant, warehouse, team and product photographs.
4. Connect the enquiry form to a secure backend/CRM. The current form opens a pre-filled email draft; it does not store submissions.
5. Confirm hosting, SSL, privacy policy and any required legal disclosures.

## Design
Corporate steel-blue palette with graphite and copper accents, responsive navigation, scroll reveals, hover motion and reduced-motion support. Design inspiration was taken from premium industrial/corporate website conventions; no third-party branding assets are used.
